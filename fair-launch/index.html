The promotion standard

01 / PRIMARY TERMS

A first-party source must name the contribution, timing, eligibility, and reward/token status.

02 / TECHNICAL TRACE

There must be a reproducible public technical record: live network evidence, signed/released code, or equivalent operational proof.

03 / INDEPENDENT CHECK

At least one non-project corroborating source must be recorded. Project docs and a project GitHub repo alone fail this gate.

04 / RISK FIRST

Every record carries an explicit risk gate. If a programme ends, enrollment closes, or terms are unclear, it is removed rather than carried forward.
